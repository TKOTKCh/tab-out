# Tab Out

**时刻掌握你的标签页。**

> [English](README.md) | **中文**

Tab Out 是一个 Chrome 浏览器扩展，它将你的新标签页替换为一个显示所有打开标签的仪表板。标签按域名分组，主页（Gmail、X、LinkedIn 等）被单独提取到一个组中。关闭标签时会有令人愉悦的 swoosh 音效和彩带动画。

---

## 🔄 Fork 信息

本项目 fork 自 [https://github.com/zarazhangrui/tab-out](https://github.com/zarazhangrui/tab-out)。以下是新增的功能：

### ✨ 新增功能

1. **空闲标签页区域** - 按上次访问时间分组：
   - 过去1小时内打开
   - 1-2小时前打开
   - 2小时以上未访问
   - 支持"关闭全部标签"和"关闭重复标签"按钮

2. **点击统计区域** - 追踪标签页点击次数：
   - 点击 ≥ 5 次（频繁访问）
   - 点击 < 5 次（中等访问）
   - 最近未点击
   - 每2小时自动刷新
   - 数据存储在本地 `chrome.storage.local`

3. **增强的重复标签提示** - 改进的清理选项：
   - "Close duplicate Tab-Out" 按钮
   - "Close allduplicates" 按钮关闭所有重复标签
   - 智能显示 - 仅在有重复时显示

4. **实时更新** - 标签页变化时自动同步：
   - 标签创建/删除时触发仪表板刷新
   - 点击追踪在后台运行

5. **其他改进**：
   - 支持 chrome:// 页面统计
   - 更好的样式和 UI 改进
   - 修复了内容安全策略问题

## 功能特性

- **一目了然** - 在清晰的网格上查看所有标签，按域名分组
- **主页组** - Gmail 收件箱、X 主页、YouTube、LinkedIn、GitHub 主页等被提取到一个卡片中
- **优雅关闭** - 带有 swoosh 音效和彩带动画
- **重复检测** - 标记重复打开的页面，一键清理
- **快速跳转** - 点击任意标签即可跳转到该标签，支持跨窗口
- **稍后阅读** - 关闭前将标签保存到清单
- **本地服务分组** - 显示端口号，方便区分不同开发项目
- **可扩展组** - 显示前8个标签，点击"+N more"可展开更多
- **空闲标签页区域** - 按上次访问时间分组显示
- **点击统计区域** - 追踪每个标签的访问频率
- **100% 本地** - 数据永远不会离开你的设备
- **纯 Chrome 扩展** - 无需服务器、Node.js、npm，只需加载扩展即可使用

## 安装

### Chrome

**1. 克隆仓库**

```bash
git clone https://github.com/TKOTKCh/tab-out.git
cd tab-out
```

**2. 加载 Chrome 扩展**

1. 打开 Chrome 并访问 `chrome://extensions`
2. 启用**开发者模式**（右上角开关）
3. 点击**加载已解压的扩展程序**
4. 导航到克隆仓库中的 `extension/` 文件夹并选择它

**3. 打开新标签页**

你将看到 Tab Out 仪表板。

### Microsoft Edge

**1. 克隆仓库**（如果还没克隆）

```bash
git clone https://github.com/TKOTKCh/tab-out.git
cd tab-out
```

**2. 加载 Edge 扩展**

1. 打开 Microsoft Edge 并访问 `edge://extensions`
2. 启用**开发者模式**（左侧边栏开关）
3. 点击**加载已解压的扩展程序**
4. 导航到克隆仓库中的 `extension-edge/` 文件夹并选择它

**3. 打开新标签页**

你将看到 Tab Out 仪表板。

## 工作原理

```
你打开一个新标签页
  -> Tab Out 显示按域名分组的所有打开标签
  -> 主页（Gmail、X 等）在顶部有自己的组
  -> 空闲标签按上次访问时间分组显示
  -> 点击统计按点击频率分组显示
  -> 点击任意标签标题即可跳转到该标签
  -> 关闭完成的组（带有音效和动画）
  -> 关闭前可保存标签供稍后阅读
```

所有内容都在 Chrome 扩展内运行。无需外部服务器、API 调用，数据不会发送到任何地方。保存的标签存储在 `chrome.storage.local` 中。
